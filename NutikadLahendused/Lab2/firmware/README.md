# Labori 2 Atomi püsivara

Arenduspäeviku järgi tehakse Atomi postilkäimise muudatusi eraldi repos [ESP32-Image-Server-Fork](https://github.com/AVeske/ESP32-Image-Server-Fork), kaustas `atom-image-server`.

Püsivara lähtekoodi selles kaustas veel ei ole; kasutatud commit tuleb täpsustada. [Serveri API](../Docs/server_api.md) kirjeldab ühendamise lepingut, mitte seadmekatse õnnestumist.
